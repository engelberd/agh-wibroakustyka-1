# Wyznaczenie krzywych przestrzennego rozkładu hałasu w pomieszczeniach oraz parametrów DL2 i DLf.

Szkielet raportu bez danych demonstracyjnych. Uzupełnij datę w `main.tex`.

- `konspekty/`: materiały zajęciowe i dokumentacja.
- `data/raw/`: oryginalne pomiary.
- `data/processed/`: uporządkowane dane i obliczenia.
- `analysis/`: skrypty opracowania.
- `figures/`: zdjęcia i szkice.
- `generated/`: tabele i wykresy do raportu.

```bash
python3 scripts/report.py build 07-krzywa-rozkladu-halasu
python3 scripts/report.py export 07-krzywa-rozkladu-halasu
```
